# Hotel Management System

## About the Project
Hotel Management System is a console-based Java application developed to manage basic hotel operations.

## Features
- Staff Management
- Restaurant and Food Management
- Customer Management
- Order Management
- Billing Management
- Room Management

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Collections

## Project Status
In Progress

## How to Run
Compile the Java files and run the Main class using the Java command line.
